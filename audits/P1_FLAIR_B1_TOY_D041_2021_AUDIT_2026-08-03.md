## Archive and Pairing Evidence

The archive has 1,083 entries, including `aerial/`, `labels/`, and
`sentinel/`. It contains 525 `aerial/**/IMG_*.tif` files and 525 matching
`labels/**/MSK_*.tif` files across the five domains `Z1_AA`, `Z2_FA`,
`Z3_NA`, `Z4_UA`, and `Z5_FN`.

The official FLAIR loading script discovers `IMG*.tif` and `MSK*.tif` within
each domain, then aligns them by their shared patch suffix. The local B1
discovery code now implements that rule while preserving each relative domain
path. The original exact-stem rule would have rejected every valid official
pair because the role prefixes differ.

Observed raw labels are `1` through `13`, `15`, and `16`; raw label `14` does

and does not train or score on the non-herbaceous classes.

The official data card specifies aerial band order as `Red`, `Green`, `Blue`,
`NIR`, `nDSM`. B1 therefore has one fixed preprocessing rule: pass channels
zero through two, in that order, to the frozen RGB CLIP encoder. The new
`load_flair_example` reader rejects a non-five-channel source raster and does
not silently include the NIR or nDSM channels.

## Decision and Remaining Gates

The official archive layout, FLAIR raw label `10`, and its nontrivial pixel
support are verified. This qualifies the data reader and narrow mapping logic
for a full-source audit.

It does **not** make `dataset_label_mappings_flair_b1_v1.yaml` ready for
training. Before B1 is defined or any GPU run starts, all of the following are
required:

1. Acquire and audit the frozen full FLAIR train/validation source set, with
   its archive hashes, paired-identifier fingerprint, and raw-label counts.
2. Pre-register a deterministic FLAIR source partition and a fixed matching
   B0/B1 update budget before seeing any OpenEarthMap result.
3. Preserve the audited channel-zero-to-two RGB selection in the B1 training
   protocol and in every cloud environment. No implicit channel truncation is
   allowed.
4. Keep only raw ID `10` as B1 supervision; every other FLAIR raw ID remains
   ignored so B1 changes source coverage rather than the six LoveDA-covered
   leaves.
